# exacerbation_patient
Étude de l'exacerbation chez des patients atteints d'asthme sous 3 projets : 
1. Développement d'un modèle de prédiction capable d'anticiper la survenue des exacerbations survenues dans l'année 
2.  Développement d'un modèle de prédiction capable de prédire le nombre d'exacerbations survenues dans l'année 
3. Génération de données synthétiques des patients asthmatiques selon la méthode avatar : approche de Guillaudeux et al. (2023)
